# Spytify has moved

Spytify lives at [spytify/spytify](https://github.com/spytify/spytify) now: the code, the issues and the releases, including Spytify 2 for Windows, macOS and Linux.

This repository only stays so that Spytify 1.12 and older still find their last update. They check its latest release, Spytify 1.13, which then points to Spytify 2.

Website: https://spytify.github.io/spytify/
